# 个人视觉规范

用于新系列的视觉设计、提示词编写和风格核对。用户本次另有指定时按新要求执行。

## 已确认的样式

| 元素 | 默认 |
|---|---|
| 画幅 | 3:4 竖版；目标 1080×1440 或更高，同套尺寸一致 |
| 背景 | 雾白 #F7F8FC；封面或关键机制页可用深墨蓝 #14172B |
| 主色 | 钴蓝 #4162FF、清蓝 #6D91FF、蓝紫 #7B63F6 |
| 辅色 | 浅薰衣草 #D9DFFF，用于淡底、细线或轻柔光感 |
| 字体 | 清晰现代无衬线中文；标题粗体，正文常规或中等；不拆断 ChatGPT、Codex 等英文名 |
| 构图 | 左对齐为主；以大标题、字重与留白建立层次；单页一个重点 |
| 装饰 | 纤细分隔线、小几何点、少量蓝紫光晕或开放圆弧 |
| 强调 | 关键词着色或渐变字；高对比优先，渐变不能让笔画消失 |
| 页码 | 封面无编号；正文左上角 01 起；右下角永远不放页码 |

这些色值来自用户认可的视觉方向，不宣称是任何公司的官方品牌规范。

## 内置风格样本

需要视觉参考时先实际查看文件，再传入图像工具：

- `../assets/style-cover.png`：深蓝封面、大字号、蓝紫光感。
- `../assets/style-content.png`：浅底内容页、开放文字区域、清晰分工层级。
- `../assets/style-benefit.png`：浅底双栏解释与效果说明。

三张均是本次用户认可系列的生成图，用作排版、字级、色彩参照。图内 ChatGPT＋Codex 的内容不是未来每篇帖子的固定文案；不得沿用旧页码、旧口号或旧事实。默认只选与当前页相关的样本，不向每张提示词堆叠全部参考图。

## 手机阅读标准

- 安全边距以宽度约 8% 为起点；正文与页头不贴边。底部留出舒适空间，不借空白另加总页数。
- 主标题通常 1–3 行；正文优先 3–5 条或一个清楚的流程，必要时拆页。
- 在原图和约手机显示宽度下检查。约 1080 像素宽图片上的正文以 30–40 像素的视觉大小为起点，页头可更小；这是设计参考，不是工具已测量的值。
- 若文本太多，先压缩重复解释或调整拆页，不把正文缩成脚注。真正影响结论的条件应写进正常可读的正文或发布文案。
- 留白服务于层次，允许内容页有不同构图，不把全套都做成一个模板。

## 避免的视觉方向

默认不用手绘、涂鸦、便签、胶带、卡通人物、荧光绿整底、大黑横条和复杂 3D 装饰；不模仿原参考作者的具体版式。不要把每段都塞进卡片框，不用无意义图标填空。

流程页尤其检查：线和箭头是否指向正确节点，文字是否压在线上，循环与验收出口是否容易区分。正文内的 01、02 等步骤数字可以保留，它们不属于页面角标。

正文（示例为上传第 5 张）：

> 这是上传第 5 张、正文第 4 页。左上角页头精确为“04 把额度用在有效执行上”。封面不计页码。右下角没有页码，不出现“05 / 06”或“04 / 05”。保留正文中的列表或流程步骤数字。
